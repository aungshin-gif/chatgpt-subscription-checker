Session JSON ဘယ်လိုယူမလဲ

  1. ChatGPT login ဝင်ထားတဲ့ browser မှာ chatgpt.com/api/auth/session ကို ဖွင့်ပါ။
  2. ပေါ်လာတဲ့ JSON အကုန်ကို Select All → Copy လုပ်ပါ (အစ { ကနေ အဆုံး } အထိ)။
  3. ဒီ page မှာ paste လုပ်ပြီး Check နှိပ်ပါ။

Token သက်တမ်းကုန်ရင် 401 တက်မယ် — session အသစ်ပြန်ယူပါ။

Unofficial checker — OpenAI ရဲ့ တရားဝင် API မဟုတ်ဘူး၊ chatgpt.com ရဲ့ internal endpoint /backend-api/accounts/check/v4-2023-04-27 ကို သုံးထားတာ။ OpenAI က ပုံစံပြောင်းရင် ပြင်ရမယ်။
